# 魚津カニバル 2026｜官方原圖互動網站

## 使用

直接開啟 `index.html`，或將整個資料夾上傳至 GitHub Pages / Netlify / 任一靜態網頁主機。
請勿分開移動 `index.html` 與 `assets/`。

## 功能
- 官方 PDF 第 1 頁上、下兩張地圖原圖作為底圖，並以透明按鈕與高亮效果疊加。
- 官方 PDF 第 2 頁的 46 間參加店家原始圖卡（圖片和原文不改動）。
- 文字搜尋（日文店名、部分文字、編號）。
- 收藏與最愛篩選；使用瀏覽器 localStorage 儲存。
- 地圖 ↔ 店家雙向選取與高亮，支援滑動與縮放。
- 手機與桌面響應式排列。

## 來源和注意
官方來源：https://www.uozu-kanko.jp/uozu-bar/img/map.pdf

地圖座標由原始 PDF 視覺標定，已建立 46 筆資料，但尚非官方精密地理座標。原始地圖和店家圖卡內容不變。店名為搜尋索引，如有疑義以官方圖卡為準。

### 檔案
- `index.html`：完整網頁，不需安裝依賴。
- `assets/map_area.png`、`assets/map_station.png`：官方地圖裁切圖。
- `assets/shops/01.png` 至 `46.png`：店家原始圖卡。
- `assets/shops.json`：店家名稱與相對位置資料。
- `assets/shops-data.js`：同一份資料以 JS 載入，支援直接開啟本機 HTML。

## 上線前檢查
建議於實際手機及桌面點選 1–46 的地圖標記驗收；特別注意地圖密集區的編號。請勿在未核對官方 PDF 變更後繼續沿用舊資料。
